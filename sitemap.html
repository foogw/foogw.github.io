Every page of the site, linked from the menu or not, and the settings each takes after ?

Settings go after ?, joined with &: missions?q=wall&c=1. A setting that is a list takes commas: skills?p=4,5. A page writes its settings into the address as you use it, so the address can always be copied and shared. A thing's own page is always by id, the game's own (map ids, skill ids, quest ids…); q on a list page is only what's typed in its search box.

The front page

./ Home: today's rotations, events, search, and every game thing's own page

With one of the settings below, the page shows that thing instead of the home page.

SettingWhat it does
qSearch text for the site-wide search
areaAn area's page, by map id: exits, services, bosses, quests, map
missionA mission's page, by map id: objectives, rewards, bosses, foes, map
dungeonA dungeon's page, by map id: each level on its map (a dungeon's area link comes here)
questA quest's page, by quest id
skillA skill's page, by skill id
heroA hero's page, by hero id
bossA boss's page, by creature id
titleA title's page, by title id

e.g. ./?q=energy surge · ./?area=146 (Lakeside County) · ./?mission=28 (The Great Northern Wall) · ./?quest=101114 (Ascalon Academy) · ./?skill=1 (Healing Signet) · ./?hero=18 (Jora) · ./?boss=100056 · ./?title=5 (Kurzick / Luxon)

Menu pages

rotations Zaishen and other rotations, the weekly bonuses

qSearch the rotations
bonusOne weekly bonus's page, by bonus id

e.g. rotations?q=kryta · rotations?bonus=1 (Extra Luck)

guides Hand-written guides

<guide>One guide, by its short name: gom, zos, drakes, spidercave, pre, reverie, fow, uw

e.g. guides?gom · guides?uw

storylines Each campaign's story as a chart of primary quests and missions

<storyline>Which campaign: prophecies, factions, nightfall, eotn
sThe step picked: q + quest id, or m + mission id
mA mission to pick, by map id (the same as s=m…)

e.g. storylines?factions · storylines?prophecies&m=28

missions The mission list

qMission name
wBoss, elite skill or foe
cCampaigns, by number: 1 Prophecies, 2 Factions, 3 Nightfall, 4 Eye of the North
tyType: story, challenge, competitive, elite, pvp
rRegion, by region id
nParty size
eHas an elite of this profession (1 Warrior … 10 Dervish)
pvp1: include PvP maps
sortstory, name, campaign, region, type, party; a leading - reverses it

e.g. missions?q=wall · missions?c=3&sort=-party · missions?w=energy surge

areas Every area in the game, by kind and region

cCampaign tab (none: all): 0 Core, 1 Prophecies, 2 Factions, 3 Nightfall, 4 Eye of the North, 5 Bonus Mission Pack, 6 the game's unknown one
kType filter: outposts (cities, outposts, mission outposts, marketplaces and cooperative missions), missionareas (mission areas and Eye of the North missions), pvp (every PvP type), else a game area type's number (e.g. 6, cooperative mission); none for all
all1: Show all, also the areas data/areas.js lists (festival copies of cities, guild halls and their copies, cinematics, arena, alliance battle and other copies, dev, test, unused and unnamed maps)
sortColumn to sort by (name, type, region, party), with - for the other way

e.g. areas?c=2&k=6

maps The world maps with every area's walkable ground

<tab>A main tab, by its name in lower case with _ for spaces: tyria, realm_of_torment…
<subtab>After the tab, one of its subtabs, named the same way
areaPicks out one area, by map id, on the map that holds it

e.g. maps?cantha · maps?realm_of_torment&gates · maps?area=146 (Lakeside County)

skills The skill list

qSkill name
tWords in the description
pProfessions, by number (1 Warrior … 10 Dervish, 0 Common)
aAttribute: a + attribute id, or t + title id for a title's PvE skills
tyType, as the wiki words it (Hex Spell), or a group: ~Attack, ~Spell, ~Ritual
cCampaign: 0 Core, 1 Prophecies, 2 Factions, 3 Nightfall, 4 Eye of the North
sSource: capture, skill trainer, hero skill trainer, quest, title
e1: elites only
pvp1: include PvP versions
sortname, profession, attribute, type, cost, activation, recharge, campaign; a leading - reverses it

e.g. skills?p=4&e=1 (Necromancer elites) · skills?a=a5&sort=recharge (Death Magic) · skills?t=interrupt

heroes Every hero by campaign, with how to recruit them

No settings.

builds Team, player and hero builds

<team>A team, by its short name: meta, luxafk, gomafk
<build>A player or hero build, by its short name: 100b, esurge, wrun, hero-e-air (hero builds are hero- + profession + name)…

e.g. builds?meta · builds?100b · builds?hero-mo-prot

builder Build a bar from a template code

codeA template code to open
bonusAttribute bonuses from runes and headgear: attribute id:bonus, comma-separated
addA skill to add to the bar, by skill id

e.g. builder?code=OwUT0Y4+GRj2oM6uvpayEEAA · builder?add=1

Old addresses

Settings after # are read as if after ?. An old link to a mission, quest, skill, hero or boss on its list page (missions#mission=28) opens it on the front page; old build and guide ids (builds#team=gom-afk) open under their short names; old maps links (maps#g=Tyria, maps#view=3) open the same tab. all-quests is now quests, and skill-quests is quests?sq=1.

e.g. missions#mission=28 · builds#build=pl-hundred · all-quests#q=mursaat
